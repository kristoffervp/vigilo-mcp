# Security

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/kristoffervp/vigilo-mcp/security/advisories/new), not in a public issue. Describe what you found and how to reproduce it.

Never include sign-in files or app settings from `.data/`, tokens, or real data from Vigilo, in a report or an issue.

## Supported versions

Only the latest release gets fixes.

## Scope

This covers the code in this repository: the local server, the sign-in flows and file handling. Problems in the Vigilo service itself belong to Vigilo AS, not to this project.
